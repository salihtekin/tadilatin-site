# tadilatin.com önizleme

Bu depo yalnızca tadilatin.com adresinde yayınlanan **önizleme** sayfasını içerir (GitHub Pages).
İçerikteki ustalar, yorumlar, fiyatlar ve hesaplar örnektir; sipariş ve ödeme alınmaz.
Tam sistem (sunucu, yönetim paneli, ödeme) özel `tadilatin` deposundadır ve VPS alınınca bu sayfanın yerini alır.
